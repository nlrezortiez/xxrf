# XXRF

XXRF — экспериментальный проект для оценки угла прихода радиосигнала по двум синхронизированным приёмникам HackRF. Проект включает библиотеку обработки, пользовательский интерфейс для наблюдения за направлением в реальном времени, измерительную утилиту для воспроизводимых прогонов, а также примеры и тесты.

Назначение проекта:

- лабораторная проверка фазового метода пеленгации;
- калибровка двухканального приёмного тракта;
- исследование влияния мощности сигнала, длины окна и качества синхронизации на угловую оценку;
- отладка прикладного пользовательского интерфейса и измерительных утилит.

## Архитектура библиотеки

Библиотека разделена на несколько слоёв.

### 1. Базовый слой работы с устройствами

Слой `xxrf::core` отвечает за инициализацию библиотеки `libhackrf`, перечисление устройств, открытие приёмников и настройку тракта:

- [`Context`](include/xxrf/core/context.hpp#L10-L31)
- [`Device`](include/xxrf/core/device.hpp#L17-L91)
- [`DeviceList`](include/xxrf/core/device_list.hpp#L20-L133)

Этот слой отвечает только за безопасную и устойчивую работу с аппаратурой.

### 2. Слой потокового приёма

Слой `xxrf::stream` формирует поток блоков квадратурных отсчётов от одного приёмника:

- [`RxStream`](include/xxrf/stream/rx_stream.hpp#L33-L189)
- [`RxStream::start`](src/stream/rx_stream.cpp#L190-L308)

Каждый блок снабжается служебной информацией, включая номер первого отсчёта.

### 3. Слой согласования двух приёмников

Слой `xxrf::sync` формирует из двух независимых потоков пары блоков, относящихся к одному и тому же временному положению сигнала:

- [`DualRx`](include/xxrf/sync/dual_rx.hpp#L83-L116)
- [`DualRx::start`](src/sync/dual_rx.cpp#L387-L590)

Без этого слоя межканальная фазовая разность не имела бы физического смысла.

### 4. Геометрический и параметрический слой

Этот слой задаёт математическую модель и основные типы данных:

- [`wavelength_m(...)` и `phase_to_angle(...)`](include/xxrf/aoa/geometry.hpp#L13-L56)
- [`Config`, `Estimate`, `Quality`, `Stats`](include/xxrf/aoa/types.hpp)
- [`Calibration`](include/xxrf/aoa/calibration.hpp#L5-L11)

Здесь определяются связь между фазой и углом, структуры конфигурации, результаты вычисления и межканальная фазовая поправка.

### 5. Слой вычисления угла

Основная математическая обработка сосредоточена в:

- [`Processor`](include/xxrf/aoa/processor.hpp#L10-L36)
- [`Processor::create`](src/aoa/processor.cpp#L229-L291)
- [`src/aoa/processor.cpp`](src/aoa/processor.cpp)

Именно здесь выполняются:

- преобразование входных данных в комплексные отсчёты;
- применение межканальной фазовой поправки;
- прореживание отсчётов;
- накопление по окну;
- вычисление межканальной фазовой разности;
- преобразование фазы в угол;
- вычисление показателей качества;
- принятие решения о допустимости оценки.

Основная логика вычисления угла сосредоточена в `Processor`.

### 6. Поточная обёртка вычислителя угла

Слой `xxrf::aoa::rt` объединяет согласованную пару приёмников и вычислитель угла в единый потоковый тракт:

- [`Stream`](include/xxrf/aoa/rt/aoa_stream.hpp#L26-L49)
- [`Stream::start`](src/aoa/rt/aoa_stream.cpp#L26-L129)

## Как `xxrf_viewer` использует библиотеку

Пользовательский интерфейс не содержит собственной математической модели угла. Он использует библиотечные слои и добавляет прикладную логику настройки, фильтрации и отображения.

### 1. Состояние пользовательского интерфейса

Файл [`ViewerState`](apps/xxrf_viewer/viewer_state.hpp#L134-L218) хранит:

- выбранные устройства;
- параметры приёмного тракта;
- параметры вычисления угла;
- историю измерений;
- состояние калибровки;
- настройки отображения и фильтрации.

### 2. Связующий слой

Файл [`apps/xxrf_viewer/viewer_actions.cpp`](apps/xxrf_viewer/viewer_actions.cpp) связывает пользовательский интерфейс с библиотекой:

- [`start_stream(...)`](apps/xxrf_viewer/viewer_actions.cpp#L106-L176)
- [`stop_stream(...)`](apps/xxrf_viewer/viewer_actions.cpp#L178-L194)

Здесь пользовательские параметры переводятся в конфигурацию вычислителя, запускается потоковый тракт и библиотечные результаты преобразуются в телеметрию пользовательского интерфейса.

### 3. Дополнительная обработка результатов

Файл [`apps/xxrf_viewer/main.cpp`](apps/xxrf_viewer/main.cpp) выполняет прикладную обработку результатов:

- контроль порога мощности с гистерезисом;
- ограничение по стороне базы;
- сглаживание угла по времени;
- накопление истории;
- формирование состояний `Below Threshold`, `Низкое качество`, `Другая сторона`.

Стрелка на экране показывает не непосредственный результат вычислителя, а дополнительно отфильтрованную и сглаженную оценку.

### 4. Построение интерфейса

За визуальное представление отвечают:

- [`apps/xxrf_viewer/viewer_ui.cpp`](apps/xxrf_viewer/viewer_ui.cpp)

## Модель вычисления угла

В проекте используется двухэлементная приёмная база. На оба приёмника поступает один и тот же сигнал, приходящий под некоторым углом относительно нормали к базе. Разность хода порождает межканальную фазовую разность, по которой восстанавливается угол.

В текущей версии решается одномерная задача:

- используется одна база длиной `d`;
- оценивается угол относительно нормали к базе;
- полная круговая пеленгация не выполняется;
- результат ограничен диапазоном `[-90°, +90°]`.

### Геометрическая связь между фазой и углом

Для плоской волны разность хода определяется выражением

$$
\Delta L = d \sin \theta.
$$

Фазовая разность между каналами:

$$
\Delta \varphi = \frac{2\pi \Delta L}{\lambda}.
$$

Отсюда следует выражение для угла:

$$
\theta = \arcsin \left( \frac{\Delta \varphi \lambda}{2\pi d} \right).
$$

Эта связь реализована в [`phase_to_angle(...)`](include/xxrf/aoa/geometry.hpp#L30-L56). Длина волны вычисляется в [`wavelength_m(...)`](include/xxrf/aoa/geometry.hpp#L13-L21).

Для однозначного восстановления угла по одной фазовой разности требуется условие

$$
d \le \frac{\lambda}{2}.
$$

Оно проверяется при создании вычислителя угла в [`Processor::create`](src/aoa/processor.cpp#L229-L291).

### Вычислительный тракт

Для каждого отсчёта вычисляется комплексное взаимное произведение

$$
z[n] = \overline{x_0[n]} \cdot x_1[n].
$$

После накопления по окну

$$
Z = \sum_n z[n]
$$

межканальная фазовая разность оценивается как

$$
\Delta \varphi = \mathrm{atan2}\bigl(\mathrm{Im}(Z), \mathrm{Re}(Z)\bigr).
$$

Далее эта величина преобразуется в угол, и одновременно вычисляются показатели качества.

## Показатели качества

Угловая оценка принимается по совокупности критериев.

### Когерентность

Когерентность вычисляется как

$$
\gamma =
\frac{\left| \sum_n \overline{x_0[n]} \, x_1[n] \right|}
{\sqrt{\left(\sum_n |x_0[n]|^2\right)\left(\sum_n |x_1[n]|^2\right)}}.
$$

Эта величина показывает степень согласованности двух каналов внутри окна обработки.

### Активная доля окна

Для каждого отсчёта вычисляется мощность в обоих каналах. Отсчёт считается активным, если меньшая из двух мощностей не ниже порога. Далее определяется доля активных отсчётов в окне.

Эта метрика особенно важна для пакетных сигналов.

### Устойчивость фазы по подокнам

Окно делится на несколько подокон. Для каждого подокна оценивается локальная межканальная фаза, после чего вычисляется круговое среднеквадратическое отклонение

$$
\sigma = \sqrt{-2 \ln r},
$$

где `r` — длина среднего результирующего вектора единичных фазоров.

## Что показывает стрелка

Стрелка в `xxrf_viewer` показывает результат следующей цепочки:

1. межканальная фазовая разность по текущему окну;
2. преобразование этой фазовой разности в угол по модели двухэлементной базы;
3. проверка по критериям качества;
4. дополнительная фильтрация по мощности и по стороне базы;
5. сглаживание по времени.

Для коротких пакетных сигналов, сильной многолучёвости или плохого согласования каналов стрелка может:

- отсутствовать;
- показывать нестабильное значение;
- переходить в состояния `Below Threshold`, `Низкое качество` или `Другая сторона`.

## Ограничения

Текущая реализация наилучшим образом соответствует непрерывному или достаточно стационарному узкополосному сигналу.

Основные ограничения:

- одна база не даёт полной круговой пеленгации;
- при пакетных сигналах окно может содержать полезную посылку, паузы и переходные процессы;
- сильная многолучёвость меняет фазовую картину;
- межканальная фазовая поправка пока считается постоянной для текущего режима, а не частотно-зависимой функцией;
- высокая когерентность сама по себе не гарантирует правильную угловую оценку;
- для практического применения требуется отдельная калибровка.
